Path attunement — neutral

Click a path to cycle neutral → attuned → repelled → neutral. Attunement mirrors your character's god/relic bonuses: an attuned path costs ~20% less and scales as if you were 4 levels higher; a repelled path costs ~25% more and scales as if you were 4 levels lower (and unlocks 4 levels later). Each spell's path(s) are listed under its name below — only matching paths are affected.

How to read this grimoire

Cost column

Each level cell shows cost if flat, or cost / effect when the spell also has a scaling magnitude. Sorcery / pyromancy / evocation / summoning spend mana; praying spends grace. Cost formula: base × (1 + max(0, (level−min level) / scale)), floored — flat if the archetype sets no scale value.

Effect column

base + floor(max(0, level−min level) / divisor), the same adjustment the server applies to damage, resistances, and similar magnitudes. Resistances cap at 100%.

Damage & healing

Healing spells restore a fixed average (dice-based) amount that does not scale with caster level in the current code — only the grace cost changes. Full heal spells restore all missing HP outright.

Resistance & summon/utility

Stat spells (Str/Dex/Con/Cha) grant a small flat, partly random bonus — not level scaled. “Summon power” reflects the summoned ally's own stat, not direct damage you deal.

Dashes & blanks

A dim — before a spell's minimum level means it can't be cast yet. Roughly half of all entries are utility effects (illusion, teleport, detection, wards) with no single tracked magnitude — only their cost is shown.

Assumptions & source

Figures default to a caster with no path attunement/repulsion — use the “Path attunement” panel above the table to model your own god/relic bonuses per path. A path your god denies outright (unlearnable, not just costlier) isn't modeled here. Multi-effect buffs (marked in source data) show only their primary number.
